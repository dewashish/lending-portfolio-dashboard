What makes the PQR what it is.

Six design choices that run through every sheet. Knowing them makes the rest of the workbook easy to read.

01

Period columns

Every sheet uses month-end periods as columns (Apr'25, May'25, Jun'25...). Read left to right to see how a metric is trending.

5 months visible
02

Metric Type → Metric

Rows are grouped by category (Book Size, Entry Rates, Portfolio Performance, Roll Rates, Process Efficiency) and then by the individual metric.

5 categories40+ metrics
03

Benchmarks inline

A Bench-mark column sits next to the latest period so a reader can judge whether the current value is acceptable without leaving the sheet.

e.g. 10-12%< 5%
04

Total + Cuts

Most sheets show the total portfolio first, then repeat the same structure for Secured, Unsecured, and key products (Personal Loan, Housing, Auto).

TotalSecuredUnsecured
05

Bucket granularity

DPD is reported per bucket: Current, 1-30, 31-60, 61-90, 91-120, 121-150, 151-180, 180-210, 210+, plus FWOF (forward write-off).

9 DPD buckets
06

Static pool / vintage

Cohort tables track how each monthly origination cohort ages over MOB-1 through MOB-7, for both X+ and 30+ delinquency.

X+ rate30+ rate

RollRateHeatmap chart on the dashboard
Five sub-metrics, repeated per bucket
Resolution

Share that left the bucket entirely (cured or written off).

Norm

Returned to a normal bucket (cure path).

Rollback

Moved backward to a lower DPD.

Stab

Stayed in the same bucket.

Roll Forward

Got worse, moved to a higher DPD.

In Summary

Eleven sheets, one consistent grammar.

Metric Type and Metric in the rows, periods across the top, benchmarks at the right, and the same structure repeated for Total, Secured, and Unsecured. Learn that once and every sheet reads quickly.
