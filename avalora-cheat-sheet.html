The AI assistant.

A panel that takes natural-language questions about the portfolio. It pulls live data from across consumer, trade, corporate, and risk domains in parallel, assembles a structured context, and streams a markdown answer using the same numbers the dashboard surfaces visually.

  • Reads the active scope (group, region, subsidiary) and the active product filter before answering.
  • Returns formatted markdown with copy-to-clipboard for board packs and chat summaries.
  • No SQL, no filter chains. The same questions a CRO would ask a junior analyst.
  • Live data on every query — never serves a stale cached answer.

Validated ingest.

Every incoming feed is schema-validated, currency-normalised, and audit-logged before it touches the data store. Bad payloads are rejected outright, not silently coerced.

  • API-key authentication on every ingest endpoint.
  • Strict typed validation rejects malformed data on arrival.
  • FX conversion applied so group totals can be computed in a common currency.

Aggregation rigour.

Rate metrics are weighted by exposure across subsidiaries. Monetary metrics are summed in a common currency. The rule is encoded in one place so every surface behaves identically.

  • Single source of truth for aggregation logic — no spreadsheet drift.
  • Same rule applied across dashboard, AI assistant, and exported reports.
  • Eliminates the manual reconciliation that used to slow down month-end.
